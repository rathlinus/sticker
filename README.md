# Sticker

Alle 235 Sticker, Stand 9. November 2026, in echter Größe zueinander: https://rathlinus.github.io/sticker/

- svg/: ein SVG pro Sticker, ohne Beschnitt und Schnittlinie. Wo die Datei keine Größe in mm angibt, sind 10 Einheiten 1 mm.
- holo-02.webp: Vorschau von Sticker 2 auf Holofolie.
- stickers.json: Abschnitte, Reihenfolge und Beschriftungen.
- index.html: die Übersicht als eine einzige Datei, alle Sticker darin eingebettet.

Nach Änderungen an svg/ oder stickers.json die Übersicht neu bauen:

```
python build.py
```
